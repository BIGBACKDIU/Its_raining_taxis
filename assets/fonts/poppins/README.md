# Poppins fonts for deck charts

Downloaded unchanged from the Google Fonts repository on 26 October 2026:

- [Poppins Regular](https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Regular.ttf)
- [Poppins Medium](https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Medium.ttf)
- [Poppins SemiBold](https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-SemiBold.ttf)

Copyright 2020 The Poppins Project Authors. Distributed under the SIL Open Font License 1.1;
see the unmodified `OFL.txt`. Exact font hashes are recorded in the deck's `audit.json`.
The plotting script registers these local files and rejects fallback fonts or missing glyphs.
No Anton callouts are used; all chart text uses Poppins.
